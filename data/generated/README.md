The first frozen release will be created only after the public/private configuration boundary is verified and the final hidden DUT/reference/chamber truth has been frozen.

Expected release contents include static, dynamic, ramp, cyclic, sinusoidal, and stability measurement files plus the test matrix and dataset manifest.
